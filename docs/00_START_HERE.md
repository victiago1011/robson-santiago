## Fluxo obrigatório

Para qualquer mudança relevante:

1. ANALISAR
2. ENTENDER O PEDIDO E O ESTADO ATUAL
3. PROPOR UM PLANO MÍNIMO
4. INFORMAR ARQUIVOS AFETADOS
5. INFORMAR IMPACTOS, DEPENDÊNCIAS E RISCOS
6. PARAR E AGUARDAR A RESPOSTA EXATA `APROVADO`
7. SOMENTE APÓS `APROVADO`, IMPLEMENTAR
8. VALIDAR TypeScript, ESLint e funcionamento do projeto
9. RELATAR O QUE FOI ALTERADO

Não implementar antecipadamente.

## Regra de escopo

Faça somente o que foi aprovado. Uma correção não autoriza refatorações paralelas, mudanças de design, instalação de bibliotecas ou criação de funcionalidades adicionais.

## Estado inicial

O projeto é o site pessoal oficial de Robson Santiago e está sendo construído em Next.js + TypeScript + Tailwind CSS. A Home será desenvolvida progressivamente a partir de referências visuais aprovadas. Toda seção visual deve nascer responsiva e ser validada em mobile, tablet e desktop antes de ser considerada concluída.
